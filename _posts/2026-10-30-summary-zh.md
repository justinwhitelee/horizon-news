### [Mistral 发布大型模型 Large 4 开源权重](https://mistral.ai/news/mistral-large-4-oss/) ⭐️ 8.0/10



hackernews · kuberwastaken · 10月29日 14:13 · [社区讨论](https://news.ycombinator.com/item?id=50289418)

#### Summary

Mistral AI 正式发布了 Mistral Large 4 的开源权重（HuggingFace 上为 Mistral-Large-4-1T-A52B），同时宣布 API 价格大幅下调——输入从 1.36 美元/百万 token 降至 0.70 美元，输出从 4.18 美元降至 2.10 美元。然而，该模型附带商业许可条款：从事 Model as a Service（MaaS）业务的许可证持有人必须与 Mistral 签订单独的商用许可协议才能用于商业目的，这一限制在社区引发了关于&quot;开源权重&quot;命名是否误导的争议。模型在公开评测中展现出 96.6% 的恶意网络请求拒绝率，为开源模型中最高。

#### Community Discussion

社区主要关注两点：一是许可证中对 MaaS 业务的商业授权限制被部分用户认为与&quot;开源&quot;宣传存在落差，类比了 Redis 和 Elasticsearch 此前的类似争议；二是 pricing 的大幅下调使模型从预览版的&quot;缺乏竞争力&quot;转变为值得重新评估的选项。另有用户指出模型的高拒绝率数据缺少对应低拒绝率的基准说明，存在统计解读上的模糊性。

### [TKintegers K5 在 L4 上实现比 TorchAO FP8 高约 3 倍的吞吐量](https://www.reddit.com/r/MachineLearning/comments/1xir3oa/tkintegers_k5_321_prefill_and_310_decode/) ⭐️ 8.0/10



reddit · r/MachineLearning · /u/Code\_MasterCody · 10月29日 17:53

#### 摘要

开发者 /u/Code\_MasterCody 发布了 TKintegers K5，一种基于平衡三进制的权重表示方法和配套 GPU 推理实现。在 NVIDIA L4（具备原生 FP8 tensor core 支持）上使用 Qwen2.5-0.5B-Instruct 模型测试，K5 的预填充吞吐量达到 3,402.85 tokens/s，是 TorchAO 动态 E4M3 FP8（1,061.58 tokens/s）的 3.21 倍；解码吞吐量为 26.75 tokens/s，是 FP8（8.63 tokens/s）的 3.10 倍。K5 将每个权重编码为 5 个平衡三进制位（共 243 种取值，占 1 字节），通过有界 tile 展开计算并配合 FP16 tensor core 操作数与 FP32 累加来实现高性能。尽管 L4 无原生 K5 指令，K5 仍能在现有硬件上超越 FP8 基线，但 FP16 控制实验仍更快。相关代码和基准测试结果已公开在 GitHub 仓库。

#### 背景

平衡三进制使用 -1、0、+1 三个值表示数字，与常见的二进制不同，TKintegers K5 利用 5 个三进制位（trit）编码一个字节，提供 243 种可能的权重值。NVIDIA L4 GPU 内置 FP8（E4M3）tensor core 支持，是当前大模型量化推理的主流高精度低比特方案之一，TorchAO 提供了易于使用的 FP8 动态量化实现。
